# Fighter models

`jazeek.glb` and `bonez.glb` are generated by `tools/characters/build.py` (Blender as a Python module) from MakeHuman 1.1
data plus original procedural textures and accessories. Rebuild:

```
tools/characters/fetch-data.sh          # once: MakeHuman data into .cache/, bpy + pillow
python3 tools/characters/build.py bonez
python3 tools/characters/build.py jazeek
```

Licences per asset: `<id>.credits.json` (CC0 MakeHuman assets; Tank_Top_01 by Mindfront is CC BY 4.0 and must be
credited in the game's credits). A hand-made or scanned model with the same Mixamo-style bone names can replace a file
here at any time (see docs/ASSETS.md).
